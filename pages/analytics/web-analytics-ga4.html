Analytics & Data

Web Analytics & GA4

Google Analytics 4 (GA4) is an event-based analytics platform: instead of pre-defined "pageviews and sessions" like older Universal Analytics, everything — a pageview, a click, a purchase — is logged as a flexible, custom-parameterized event.

Installing GA4

index.html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>

Sending a custom event

track-signup.js
document.getElementById('signup-btn').addEventListener('click', () => {
  gtag('event', 'sign_up', {
    method: 'email',
    campaign: 'homepage_hero'
  });
});

// Standard e-commerce purchase event
gtag('event', 'purchase', {
  transaction_id: 'T12345',
  value: 49.99,
  currency: 'USD',
  items: [{ item_id: 'SKU123', item_name: 'Trail Shoe', price: 49.99, quantity: 1 }]
});

Core GA4 concepts

ConceptMeaning
EventAny interaction logged — page_view, click, scroll, purchase, and custom ones you define
ParameterExtra detail attached to an event (e.g., value, currency on a purchase event)
Conversion (Key Event)Any event you mark as a meaningful business outcome (e.g., sign_up, purchase)
AudienceA segment of users defined by behavior/attributes, usable for remarketing or analysis
ExplorationsFree-form report builder for funnel, path, and cohort analysis

Google Tag Manager (GTM)

GTM lets marketers deploy and manage tracking tags (GA4, ad pixels, custom scripts) through a visual interface, without editing site code for every change. It works via Tags (what to fire), Triggers (when to fire it), and Variables (dynamic values used by tags/triggers).

gtm-trigger-example.txt
Trigger: Click - All Elements
  Condition: Click Classes contains "cta-button"
Tag: GA4 Event
  Event Name: cta_click
  Parameters: { button_location: {{Click Text}} }

Essential GA4 reports

  • Acquisition — which channels (organic, paid, social, referral, direct) bring traffic
  • Engagement — pages/events users interact with most, average engagement time
  • Monetization — revenue, purchases, e-commerce performance
  • Retention — how many users return after their first visit
⚠ Common Mistake

Not marking key business events ("Key Events" in GA4, formerly "Conversions") explicitly. Without this, GA4's default reports won't reflect what actually matters to the business, and automated bidding tools that rely on this data won't optimize correctly.

🎯 Interview Corner

Q: What's the fundamental difference between GA4 and old Universal Analytics?
A: Universal Analytics was built around sessions and pageviews as first-class concepts. GA4 is event-based: literally everything, including a pageview, is just an event with parameters. This makes GA4 more flexible for tracking app + web behavior and cross-device journeys, but requires deliberately defining what counts as a meaningful event.
