On-Page SEO

On-page SEO is everything you control directly on a page — HTML structure, content, and internal links — to help search engines understand exactly what it's about and who it's for.

Title tag & meta description

The title tag is the single strongest on-page ranking signal and the blue link users click in search results. The meta description doesn't directly affect rankings but heavily influences click-through rate.

index.html
<head>
  <title>Best Trail Running Shoes for Wide Feet (2026 Guide)</title>
  <meta name="description" content="We tested 14 pairs over 3 months. See which
    trail running shoes actually fit wide feet without sacrificing grip." />
  <link rel="canonical" href="https://example.com/wide-feet-trail-shoes/" />
</head>
  • Keep titles under ~60 characters so they don't get truncated in search results.
  • Put the primary keyword near the front, but write for humans first — a title that gets no clicks ranks nowhere.
  • Every page needs a unique title and description; duplicates confuse ranking signals.

Heading structure

Use exactly one <h1> per page (the main topic), then <h2>/<h3> to organize subtopics logically — the same way this page is structured. Headings help both search engines and skimming readers, and they're what AI answer engines pull from when generating summaries.

Structured data (schema markup)

Schema.org markup, written as JSON-LD, tells search engines exactly what type of content a page contains, unlocking rich results like star ratings, FAQs, and recipe cards.

faq-schema.json
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "How long does SEO take to show results?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "Most sites see meaningful movement in 3-6 months, with compounding gains after 12 months of consistent work."
    }
  }]
}
</script>

Image optimization

image.html
<img
  src="trail-shoe-wide-fit.webp"
  alt="Side profile of a wide-fit trail running shoe showing the reinforced toe box"
  width="800" height="600"
  loading="lazy"
/>
  • Descriptive alt text — for accessibility and image search; describe the image, don't stuff keywords.
  • Modern formats (WebP/AVIF) and explicit width/height reduce file size and prevent layout shift (a Core Web Vital).
  • loading="lazy" for below-the-fold images improves initial page load.

Internal linking

Link between related pages using descriptive anchor text (not "click here"). Internal links pass authority ("link equity") to important pages and help crawlers discover new content faster. A common structure is the topic cluster model: one comprehensive "pillar" page links out to several narrower "cluster" pages, which link back to the pillar.

Content quality checklist

  • Matches the search intent you identified during keyword research.
  • Covers the topic more thoroughly or more clearly than the current top 3 results.
  • Includes original insight, data, or examples — not a rewrite of existing top results.
  • Readable: short paragraphs, subheadings every 200–300 words, no walls of text.
🎯 Interview Corner

Q: If you could only fix three on-page SEO issues on a client's site today, what would they be and why?
A: A strong answer prioritizes by impact-to-effort: (1) fix missing/duplicate title tags site-wide (huge, fast impact), (2) fix any pages targeting the same keyword (cannibalization — consolidate them), (3) add internal links from high-authority pages to priority pages that currently have few links.
