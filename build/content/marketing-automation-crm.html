Marketing Automation & CRM

Marketing automation triggers the right message to the right person based on their behavior — without a human manually sending each one — turning a static list into a responsive nurture system.

Common automation triggers

Trigger eventAutomated response
New signupWelcome series (3-5 emails over 1-2 weeks)
Cart abandonmentReminder email(s), often escalating to a discount by the final touch
Downloaded a lead magnetNurture sequence building toward a sales conversation or offer
No engagement in 60+ daysRe-engagement / win-back sequence, then list suppression if still inactive
Made a purchaseOnboarding sequence, then post-purchase cross-sell timed to typical reorder window

Lead scoring

Assigns points to a lead based on demographic fit and behavioral engagement, so sales teams prioritize the leads most likely to convert instead of treating every lead identically.

lead-scoring.js
function scoreLead(lead) {
  let score = 0;
  if (lead.jobTitle?.includes('Director') || lead.jobTitle?.includes('VP')) score += 20;
  if (lead.companySize > 50) score += 15;
  if (lead.visitedPricingPage) score += 25;
  if (lead.downloadedCaseStudy) score += 10;
  if (lead.emailOpens > 3) score += 10;
  if (lead.daysSinceLastActivity > 30) score -= 15; // decay for staleness
  return Math.max(score, 0);
}
// Leads scoring above a threshold (e.g. 50) get routed to sales;
// below it, they stay in automated nurture.

Marketing automation vs. CRM

Marketing AutomationCRM
Primary jobNurture leads at scale with triggered messagingTrack individual relationships and deals through a sales pipeline
Owned byMarketingSales
ExamplesHubSpot Marketing Hub, Mailchimp, ActiveCampaign, KlaviyoSalesforce, HubSpot CRM, Pipedrive

Modern platforms increasingly blur this line (HubSpot offers both), but conceptually: automation decides what message to send when; a CRM tracks where each specific person/deal stands. They typically sync data both ways so a lead's engagement history informs sales conversations.

🎯 Interview Corner

Q: How would you design a lead-scoring model with no historical conversion data yet?
A: Start with qualitative, common-sense weighting (firmographic fit + high-intent behaviors like pricing-page visits), launch it, then retrain the weights once you have enough closed-won/closed-lost data to see which signals actually correlated with real conversions — treat the first version as a hypothesis, not a final answer.
