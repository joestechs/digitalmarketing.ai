Practical Projects

Reading about digital marketing only gets you so far. These ten projects turn every section of this guide into something you actually build, run, or ship — the kind of proof-of-work that stands out in a portfolio or interview.

1. Personal SEO Audit

Beginner

Pick any website (yours, a friend's, or a local business that agrees). Run a full technical + on-page SEO audit: check title tags, meta descriptions, heading structure, Core Web Vitals via PageSpeed Insights, robots.txt, and sitemap validity. Deliver a prioritized fix list.

Google Search ConsolePageSpeed InsightsScreaming Frog (free tier)

2. UTM Link Builder Tool

Beginner

Build a small web app (HTML/CSS/JS) that takes a base URL and campaign details and generates a properly-formatted, lowercase, underscore-normalized UTM-tagged link — with a one-click copy button and a history of previously generated links stored in memory.

HTMLCSSVanilla JS

3. Buyer Persona Deck

Beginner

Interview 3-5 real people who'd plausibly buy a product of your choosing. Synthesize the interviews into 1-2 complete buyer personas using the template from the Buyer Personas guide, and present findings as a short slide deck or one-pager.

InterviewsGoogle Slides / Canva

4. 4-Week Content Calendar with Pillar/Cluster Map

Intermediate

Choose a niche, do real keyword research (free tools are fine), build a pillar + 6 cluster topic map, and lay out a 4-week publishing calendar with target keyword, funnel stage, and format for each piece.

Google Keyword PlannerGoogle SheetsSearch Console (if available)

5. Mock Google Ads Campaign Build

Intermediate

Structure a complete (unpublished) Google Ads campaign for a product: campaign settings, 2-3 tightly-themed ad groups, keyword lists with match types, 5+ negative keywords, and 3 Responsive Search Ad variants per ad group with varied headline angles.

Google Ads Editor / Keyword Planner

6. Email Welcome Series (Coded, Not Just Written)

Intermediate

Write and hand-code (table-based HTML) a 5-email welcome sequence for a fictional product, including subject lines, preview text, and one clear CTA per email. Test rendering in at least two email clients using a free tool like Litmus's trial or a Gmail test send.

HTML tablesInline CSSMailchimp free tier

7. GA4 + GTM Tracking Implementation

Intermediate

On a real or demo site, install GA4 via Google Tag Manager, configure 3+ custom events (e.g. form submit, CTA click, scroll depth), mark one as a Key Event, and build a Looker Studio dashboard pulling from that GA4 property.

Google Tag ManagerGA4Looker Studio

8. Full A/B Test with Real Statistical Analysis

Advanced

Design a genuine A/B test on a landing page or email (two real variants), run it to a pre-calculated sample size, and analyze significance yourself using a two-proportion z-test (code provided in the CRO guide) rather than only trusting a platform's built-in "winner" declaration.

JavaScriptA/B testing tool or manual splitBasic statistics

9. Multi-Channel Campaign Strategy Brief

Advanced

Write a complete strategy brief for a hypothetical product launch spanning SEO, paid social, email, and content — including SMART goals, budget allocation logic, an attribution approach, and a 90-day KPI dashboard mockup. This is the closest simulation of a real marketing-manager work sample.

Google Docs / NotionSpreadsheet budget model

10. This Website's Analytics Layer

Advanced

Fork this very site's repo, add real GA4 tracking plus custom events for the interview accordion opens, pill filter clicks, and copy-button usage, then build a simple dashboard analyzing which topics get the most engagement. A genuinely meta way to practice implementation on content you already understand deeply.

GA4Custom JS eventsLooker Studio
💡 How to use these in a portfolio

For each project, write a short case-study-style writeup: the goal, your process, what you'd have measured in a real scenario, and what you'd do differently at scale. That reflective layer is what turns a class exercise into an interview-ready portfolio piece.
